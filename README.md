Kidney Disease Classification Using Deep Learning

Project Overview

This project focuses on classifying kidney disease images using deep learning and a Convolutional Neural Network (CNN).

The project demonstrates a machine learning workflow, including data preparation, model training, evaluation, experiment tracking, and deployment.

Project Objectives

- Prepare and organize the dataset.
- Build and train a CNN model.
- Evaluate model performance.
- Track experiments using MLflow.
- Manage machine learning pipelines using DVC.
- Provide a web application for model interaction.

Technologies Used

- Python
- TensorFlow / Keras
- CNN (Convolutional Neural Network)
- MLflow
- DVC (Data Version Control)
- Flask
- Docker and GitHub Actions (deployment workflow)

Project Workflow

1. Configure the project.
2. Prepare the dataset.
3. Train the deep learning model.
4. Evaluate model performance.
5. Track experiments with MLflow.
6. Manage the pipeline with DVC.
7. Run the application.

How to Run

The project requires a Python environment and the dependencies listed in "requirements.txt".

pip install -r requirements.txt
python app.py

These commands assume the dependencies are installed and the dataset and model files are configured correctly.

MLflow and DVC

MLflow helps track machine learning experiments and their parameters and metrics.

DVC helps manage datasets and reproduce machine learning pipelines.

Dataset and Model Evaluation

The dataset must be obtained from an authorized source and configured according to the project settings.

Model performance should be evaluated using appropriate metrics on held-out test data. Results should be reported only after the model has been run and evaluated.
